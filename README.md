# HP EliteBook 840 G5 Sequoia EFI
Fetch the OC folder from releases and then use OCAT to mount esp and paste the OC folder.\
This Hackintosh EFI was made for MacOS Sequoia.
###
AT FIRST BOOT YOU MIGHT NEED TO BOOT FROM FILE, AFTER IT WILL SHOW IN F9 PICKER\
This EFI was made to work with heliport.\
I recommend using Unplugged to install MacOS because sometimes the regular installer does not work.
### What works
Bluetooth\
WiFi (using heliport)\
Everything except S3 Sleep\
